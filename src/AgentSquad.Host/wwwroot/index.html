Agent roles

  • Maintenance Coordinator — deterministic orchestration, lifecycle, concurrency, hard policy. It decides what is permitted.
  • Dependency Sentinel — confirms package and advisory evidence via NuGet, GitHub Advisory, and Tavily.
  • Patch & Verify — stages the manifest-only patch, restores, tests, rescans, and collects the diff.
  • NVIDIA Nemotron — writes the evidence-grounded risk explanation. No package, command, or release choice.
